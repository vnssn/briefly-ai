# FlyRank capstone acceptance checklist

Source: assignment screenshots and Q&A provided by Vansh on 14 October 2026.

## Product

- Small, complete frontend application solving a real problem.
- Meaningful AI integration using an LLM of our choice.
- Accessible, responsive components; target WCAG 2.1 AA.
- Structured AI output, validation, fallback behavior, and visible error states.
- Live, functional deployment and linked GitHub/GitLab repository.

## Evidence and documentation

- Project brief: problem, intended users, and reason for choosing the idea (one paragraph).
- README: setup, run commands, architecture, AI integration and prompt rationale, limitations, future improvements.
- Tests that run and pass; cover at least 50% of components and include failure paths.
- Save actual test output/coverage evidence.
- Actual mobile Lighthouse audit: target 90+, minimum stated pass score 85.
- Actual axe or WAVE accessibility audit; fix WCAG AA violations.
- Document one concrete improvement based on audit findings.
- Deployment checklist with verified items; do not sign off unverified items.
- Document safe failures, monitoring, and rollback procedure.
- Reflection (maximum one page): hardest part and why, what to do differently, and a surprising lesson. Personal claims require Vansh's review.
- Single structured portfolio submission linking the above.

## Q&A clarifications

- Existing React projects are allowed; Next.js is not mandatory.
- Any LLM provider is allowed.
- The capstone is assessed against its own criteria.
- Certification also depends on track assignments and FE-12; completing this capstone alone does not guarantee certification.
